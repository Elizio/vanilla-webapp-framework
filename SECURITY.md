# Security Policy

## Supported Versions

Only the latest version on the `master` branch and the live deployment at https://dsfor.fun/vanilla-webapp-framework are actively supported. Older commits and forks are not supported.

## Reporting a Vulnerability

**Do not open public issues, pull requests, or discussions for security vulnerabilities.**

Please report security vulnerabilities privately through GitHub's security advisory feature:

**[Report a vulnerability](https://github.com/Elizio/vanilla-webapp-framework/security/advisories/new)**

When submitting a report, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The affected component or file
- The potential impact (if known)

## What to Expect

After you submit a vulnerability report:

1. **Acknowledgement**: We will acknowledge receipt of your report
2. **Investigation**: We will investigate the issue and develop a fix
3. **Fix deployment**: The fix will be merged to `master` and automatically deployed to production
4. **Public disclosure**: We will coordinate with you on public disclosure through a GitHub security advisory after the fix is deployed

Thank you for helping keep this project secure.
